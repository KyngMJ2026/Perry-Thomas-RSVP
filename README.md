# Perry-Thomas RSVP Website

This version is built to visually match the approved Winter Wonderland invitation design.

## Behavior
- Clicking **I'LL BE THERE** on the invitation scrolls to the live RSVP form and preselects **Happily accepts**.
- Clicking **CAN'T MAKE IT** scrolls to the same form and preselects **Unable to attend**.
- The RSVP form is real HTML, not part of the image.
- The form is currently in preview mode and can be connected to Google Sheets next.
